# Фикстура: магазин

Вымышленный магазин, без данных реальных проектов: главная, хаб каталога (`listing: true`), две категории, страница товара
по шаблонному адресу `/katalog/{slug}` (`template: true`), поиск, корзина и кабинет (`ui_role`), страница без брифа и
оферта вне работы (`ui_role: legal`). `work/catalog/catalog-spec.json` - фильтры всех типов, `values_source` (значения
лидеров - с пометкой «пример»), группы без значений; `listing.cards_per_page: 8`. `work/catalog/sample-items.json` - два
товара сайта разных категорий с фото (крошечные png в `work/catalog/samples/`, встраиваются один раз) и карточка `"*"`.
Проверяет рендер каталога по контракту C5: выдача категории (свои примеры, чужие не подставляются), выдача хаба (по примеру
каждой дочерней категории, затем копии), плашки «нужны данные», пометки «пример», фильтр по facets, страница товара с
примером по `?item=`.

Фильтры по категориям (K6): «Высота сиденья» с `categories: ["katalog-stulya"]` - только на выдаче стульев; у
«Назначения» `values_by_category` - свои значения у столов, у хаба и стульев плашка «нужны данные»; у «Материала»
`labels: ["Порода дерева"]` - подпись чипа писателя, чип живой; у «Цены» явное `field: "price"`. Значения и диапазон
панели - по карточкам своей страницы.

Действия кнопок (K7): главная кнопка хаба и категорий - `action: "anchor:listing"` (к выдаче), заявка у категорий -
вторая кнопка (`secondary_action: "lead"`), на главной вторая кнопка «Смотреть каталог» - `page:katalog`, у товара -
`lead`. Тест - `.claude/tests/site-tekst/cases-site.mjs`.
