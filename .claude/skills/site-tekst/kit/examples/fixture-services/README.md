# Фикстура: сайт услуг

Вымышленная компания, без данных реальных проектов. 7 рабочих страниц (главная, хаб услуг, две услуги, услуга без брифа,
о компании, контакты) и юридическая страница вне работы (`status: skip`, `ui_role: legal`). Адреса со слешем на конце.
Проверяет прототип-сайт без каталога: `niche.business_type: services`, у хаба старая пометка `listing: true` и элемент
`filters` в блоке листинга (каталога и чипов все равно нет, подписи - простым списком), блок `pattern: custom`
(`custom_name` - калькулятор), блок незнакомого pattern (`timeline`), галерея-слайдер на раскладке типа, форма с
полями `tel`, `email`, `textarea`, `file`, плейсхолдер `[[нужно: ...]]` в сноске формы, первый экран главной на
раскладке `hero-center` (сборщик добавляет медиа-колонку), карта на контактах, каналы в старой (строка) и новой (объект)
форме. Готовые `brief.json`, блоки и `lint-*.json` (pass): сборка без build-briefs и линтера.

Сборка: скопировать `config/` и `work/` поверх папки проекта kit, затем `node scripts/build-html.mjs`,
`node scripts/check-html.mjs` (код 0), `node scripts/check-site-js.mjs` (pass). Тест - `.claude/tests/site-tekst/cases-site.mjs`.
