# Решения по проекту (заполняется до гейта 1)

Файл копируется в `rules/decisions.md` проекта и заполняется оркестратором или человеком.
Писатели его не читают: все решения попадают к ним через `strategy.json` и `brief.json`.
Стратег и аудиторы читают этот файл целиком.

## 1. Конфликты фактов

Когда цифра из паспорта спорит с антиобещанием или с другой цифрой, здесь фиксируется
одна разрешенная формулировка. Правило по умолчанию: антиобещание сильнее цифры.

| Факт | Конфликт | Разрешенная формулировка | Где можно |
|---|---|---|---|
| F.. | | | |

## 2. Валюта и единицы

- Валюта цен: как в паспорте фактов.
- Валюта сделок и порогов: как в паспорте фактов.
- Пересчет: запрещен.

## 5. Блок оговорок

Где живет юридическая оговорка (доходность, сроки, гарантии): один блок на странице
или подвал. В первый экран оговорки не попадают.

## 6. Страницы вне периметра

Страницы карты, которые противоречат анализу (например, гео за пределами заявленного)
и решение по ним: писать коротким набором блоков без локальных фактов / не писать.

## 7. Пожелания заказчика

Формулировки, которые заказчик уже одобрил (из `inputs/client-preferences.md`), и статус:
кандидат для селектора / основа / отклонено с причиной.
