# Трассировка COPY-AUDIT.md: v6 -> v7 (этап B)

Обязательная таблица трассировки правил (программа v7, раздел «Этап B»): каждое правило
старого файла -> новое место | снято + причина. Снятие разрешено ТОЛЬКО для мертвых ссылок
(форматы и файлы, которых в v7 не существует). Базовая ревизия старого файла - состояние
COPY-AUDIT.md на ветке до переписывания (последняя правка - fc431ea).

## Инварианты, удержанные при переписывании

- **Нумерация пунктов 1:1.** П.0-П.22 сохраняют номера и темы без изменений -
  `verify-copy.mjs` ссылается на эти номера в коде и печати нарушений (например
  П.8 ложный дефицит, П.13 типографика) и держит копию стоп-листа CTA (`CTA_STOP`);
  параллельный автор verify-copy рассчитывает на стабильность номеров.
- **Стоп-лист CTA (П.22, F3) - дословно**, тот же состав: Отправить, Отправить заявку,
  Отправить сообщение, Отправить вопрос, Подробнее, Узнать больше, Читать далее, Далее,
  Перейти, Оставить заявку без предмета, Submit (копия живет в verify-copy.mjs, CTA_STOP).
- **Смысл проверок 1:1**: приоритет СМЫСЛ+ГРАМОТНОСТЬ первым; пол чинится текстом, а не
  снятием; «снял продающий элемент - добери смыслом»; допуск лимитов ±15% в обе стороны;
  анти-ИИ не ищется (ADR-022); lexicon неприкосновенен; две ленты пометок; лимиты
  не доливаются водой после легального реза.

## Сводка изменений

**Снято (только мертвые ссылки, 3 позиции):** индексный разбор регистра
(chosen -> axes_from -> recommended, axes[индекс]) и зеркало blueprint.register - умерли
вместе со старой формой decisions.register (контракты 3.2 и раздел 6); ремарка о
VOICE.md-состоянии v6 в П.13; inputs.json как адрес forbidden_wordings (поле в
inputs.json v2 не пишется - контракты 2.1).

**Добавлено (все - из контрактов v7 или подъем действующего правила в файл):** раздел
«Лайт-прогон тон-гейта» (контракты 3.4); «когда прогоняется - три касания» (контракты 3.4:
лайт-прогон и применение фидбека тон-гейта - обязанности copy-auditor); подпункт
«Лексикон неприкосновенен» в П.0 + следствия в П.10/П.11 (ADR-033; ранее жило только
в запретах агента - смысл не менялся, поменялся носитель); строка деградации
forbidden_wordings при --from-table (ADR-031).

**Не менялось:** нумерация 0-22, состав и порядок тем, стоп-лист CTA, таблицы замен
П.2/П.5/П.8/П.14/П.15/П.20, все тесты (ФАС, подстановка, пропуск, деловое письмо,
«по одним заголовкам»), пороги (60/160/±15%/20 слов/40-70%), зоны ответственности
(block-planner - состав, site-reviewer - межстраничное, tekst-verifier - суждение пола,
оркестратор - waiver).
